# Vita Server Common

Vita Server Common 是一个集中化的服务端通用功能库，提供了一套企业级的云服务集成、支付、通信等核心能力，帮助快速构建可靠的微服务应用。

## 模块详细说明

### artc

**功能：** 生成阿里云实时通信（ARTC）Token

**主要能力：**
- 生成 ARTC Token，支持视频通话、音频通话、直播等实时通信场景
- Token 包含应用 ID、频道 ID、用户 ID 等信息
- 支持自定义过期时间，默认 24 小时

**应用场景：** 实时音视频通话、直播、互动应用

---

### log

**功能：** 分布式链路追踪日志模块

**主要能力：**
- 支持 trace ID 在日志中的自动注入和高亮显示
- 提供自定义日志格式化器（TraceFirstTextFormatter）
- 将 trace ID 优先显示在日志输出中，便于链路追踪
- 集成 logrus 日志库

**应用场景：** 微服务链路追踪、日志聚合、问题排查

---

### nacos

**功能：** Nacos 服务发现、配置中心与 gRPC 服务调用

**主要能力：**
- **服务发现**：从 Nacos 动态获取健康的服务实例地址
- **服务注册**：将本地服务注册到 Nacos
- **配置加载**：从 Nacos 配置中心加载应用配置
- **gRPC 服务调用**：通过 Nacos 发现并自动调用远程 gRPC 服务
- **连接池管理**：维护可复用的 gRPC 连接，自动处理连接健康状态和重连
- **链路追踪**：自动将 trace ID 注入 gRPC 请求上下文
- **故障重试**：调用失败时自动重试（最多 2 次），提高可靠性

**应用场景：** 微服务架构、服务间通信、配置动态更新

---

### oss

**功能：** 对象存储服务（OSS）驱动

**主要能力：**
- **支持多种存储后端**：阿里云 OSS、MinIO 等
- **文件上传/下载**：支持单文件和分片上传
- **文件管理**：删除、查询、更新对象元数据
- **访问控制**：支持临时访问凭证（STS）
- **签名 URL 生成**：生成可分享的临时访问链接

**应用场景：** 文件存储、媒体资源管理、备份和归档

---

### pay

**功能：** 支付服务集成

**主要能力：**
- **支付宝支付**（Alipay）
  - 支持页面支付、扫码支付、APP 支付等
  - 支持沙箱环境和生产环境
  - 自动处理回调通知和订单对账
- **微信支付**（WeChat）
  - 支持多种支付方式（Native、H5、APP 等）
  - 自动处理回调和签名验证

**应用场景：** 在线支付、订单收款、财务对账

---

### localtime

**功能：** 本地时间解析

**主要能力：**
- 支持多种时间格式解析：RFC3339、RFC3339Nano、ISO 8601、自定义格式等
- 自动将解析的时间转换为本地时区
- 容错处理，支持多种常见时间格式

**应用场景：** 时间数据解析、时区转换、日期时间处理

---

### lindorm

**功能：** 阿里云时序数据库（Lindorm）客户端

**主要能力：**
- **时间序列数据存储和查询**：高效存储海量时序数据
- **连接管理**：自动管理数据库连接
- **认证**：支持用户名/密码认证
- **查询接口**：提供 SQL 查询能力

**应用场景：** 监控数据收集、指标存储、时序数据分析

---

### mobile

**功能：** 移动端一键登录

**主要能力：**
- 通过阿里云 Dypns API 获取用户手机号
- 支持一键登录流程，无需用户手动输入
- 安全的身份验证

**应用场景：** App 用户注册、便捷登录、身份认证

---

### sms

**功能：** 短信服务（多服务商支持）

**主要能力：**
- **多服务商支持**：
  - 阿里云短信（Aliyun DySMS API）
  - 腾讯云短信（Tencent Cloud SMS）
  - 火山引擎短信（Volcano）
- **发送短信**：支持模板短信、验证码、通知等
- **费用控制**：支持限流、缓存等机制
- **回调处理**：支持短信状态回调

**应用场景：** 短信验证码、营销推送、实时通知
